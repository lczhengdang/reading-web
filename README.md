# 考研阅读 · Web 版

纸面印刷风格的考研外刊双语阅读应用：126 篇考研同源外刊（含真实《卫报》文章）、逐段中英对照、豆包大模型 2.0 云端朗读、点词查词（本地词典 + 大模型在线查词）、生词本、收藏、阅读进度记忆。纯静态前端、无框架依赖，可"添加到主屏幕"当 App 用（支持离线阅读）。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 文章库 + 筛选 + 搜索 | 来源 / 话题 / 难度分组筛选，收藏过滤，全文搜索 |
| 双语对照阅读 | 逐段译文开关 + 一键全部展开，字号可调 |
| 云端语音朗读 | 豆包语音合成大模型 2.0（16 个官方音色可选），本地代理转发；离线时可切系统浏览器语音 |
| 点词查词 | 本地 3388 词词典优先（词性 + 音标 + 中英释义）；未收录自动联网，可配置大模型查词（流式返回），多源降级 + 自动重试，结果缓存本地 |
| 生词本 | 一键加入生词本，词性标注 / 发音 / 删除 / 清空 |
| 收藏与进度 | 星标收藏文章；自动记忆阅读段落，重开"继续上次阅读" |
| PWA 离线 | Service Worker 缓存页面与读过的文章，无网络可读；可安装到主屏幕 |

## 架构

```
┌─────────────────────────── 浏览器 ───────────────────────────┐
│  index.html（hash 路由单页应用，无框架）                       │
│    js/app.js   路由与页面渲染（文库/阅读器/生词本/设置）        │
│    js/ui.js    基础 UI（图标/弹窗/Toast）                      │
│    js/tts.js   双引擎朗读（Web Audio 播放，免疫自动播放拦截）   │
│    js/dict.js  查词服务（本地词典 → 大模型/在线多源降级链）     │
│    js/store.js localStorage 持久化（设置/收藏/生词/进度）       │
│  sw.js         Service Worker（离线缓存，版本号构建时注入）     │
└───────────────┬──────────────────────────┬───────────────────┘
                │ 静态资源                  │ POST /api/tts2（同源代理，绕过 CORS）
                ▼                          ▼
┌────────────────────────┐    ┌──────────────────────────────────┐
│  静态文件服务            │    │  tools/serve.py 本地代理          │
│  （同一进程提供）         │    │  ① 转发豆包 TTS 2.0 请求          │
│  data/*.js 索引与词典    │    │  ② 解析 JSON Lines base64 分片    │
│  data/articles/ 懒加载   │    │  ③ 拼成完整 mp3 返回浏览器        │
└────────────────────────┘    └──────────────┬───────────────────┘
                                             │ HTTPS
                                             ▼
                              火山方舟 openspeech（seed-tts-2.0）
```

**要点**：

- **纯静态前端**：无构建框架、无 npm 运行时依赖（Node 仅用于数据构建工具），任意静态服务器可托管。
- **本地代理层（tools/serve.py）**：浏览器无法直连火山方舟（CORS 限制），代理服务器以标准库实现转发：调用豆包 TTS 2.0 单向流式接口，将响应的 JSON Lines（base64 音频分片）逐行解码拼接为完整 mp3 返回。多线程服务，合成不阻塞页面请求。
- **Web Audio 播放（js/tts.js）**：点击手势内解锁 AudioContext，合成返回后 `decodeAudioData` + `AudioBufferSourceNode` 播放，从机制上绕开浏览器自动播放策略；支持暂停/断点续播/全文连播。
- **缓存策略（sw.js）**：前端代码与数据产物网络优先（刷新即最新，离线退缓存）；文章正文缓存优先（读过即可离线）。缓存版本号由构建脚本按内容哈希注入，代码变更自动触发客户端更新。
- **版本可观测**：构建时向 `js/app.js` 注入 `APP_VERSION`，控制台与设置页均可见，便于确认客户端运行的是最新版。

## 使用方法

### 1. 启动（电脑上）

**双击项目根目录的 `start.bat`**：自动清理占用端口的旧服务器，启动带 TTS 代理的服务。终端会显示访问地址，**以终端输出的端口为准**（端口被占用时自动顺延）。

命令行方式等价：

```powershell
python tools/serve.py 8080
```

> 必须用 `tools/serve.py` 启动（而非 `python -m http.server`）——云端朗读依赖它的 TTS 代理。保持窗口开着；代码更新后需重启该窗口。

### 2. 配置豆包 2.0 朗读（可选）

1. 在火山方舟控制台 → API Key 管理 创建 API Key
2. 页面「设置 → 朗读引擎」选择"云端 · 火山方舟"
3. 填入 API Key、选择音色（16 个官方音色），保存即可

仅填这两项，端点/模型/接口协议全部内部管理；Key 只存在本机浏览器 localStorage。

### 3. 手机访问

手机与电脑同一 Wi-Fi，浏览器打开 `http://<电脑局域网IP>:8080`（`ipconfig` 查看无线网卡 IPv4）。首次连接 Windows 防火墙弹窗请选择"允许 Python 联网"。

### 4. 添加到主屏幕

Android Chrome：打开页面 → 菜单 → "安装应用 / 添加到主屏幕"。首次加载后支持离线阅读。

### 5. 大模型查词（可选）

「设置 → 大模型查词」配置方舟兼容接口（端点 / API Key / 模型）后，本地词典未收录的词优先走大模型流式释义，失败自动回退在线词典。

## 数据说明

- `data/articles/*.json`：126 篇文章源文件（20 篇原创 + 106 篇卫报开放平台真实文章），逐段中英对照，文件名须与文章 `id` 一致，正文按篇懒加载
- `data/dictionary.json`：3388 词本地词典（词性 + 音标 + 中文释义；`data/dict-fix/` 为历史损坏释义的修复补丁）
- `data/index.js` / `data/dict.js`：构建生成的首屏数据（元信息索引 + 词典），勿手改

### 更新文章数据（卫报）

```powershell
npm run update-guardian
# 等价于：fetch-guardian → clean-raw → curate-raw → apply-zh → fix-wordcount → build-data
```

新增文章需先在 `data/zh-add/` 补充中文译文（batch-*.json），`apply-zh` 才能合并；缺译文的文章会跳过并列出。

重新生成数据（修改文章/词典后）：`npm run build`（含 schema 校验 + 自动注入缓存版本号与 APP_VERSION）。

## 常见问题

- **朗读提示"音频播放被浏览器拦截"或"解码失败"**：先核对设置页显示的版本号与服务器终端输出是否一致；不一致按 Ctrl+F5 强制刷新。仍异常则检查浏览器地址栏 → 网站设置 → 「声音」是否被阻止。
- **朗读提示"请重启服务器"**：说明运行的是旧版服务器，关闭旧窗口重新双击 start.bat。
- **Failed to fetch**：服务器窗口被关闭或崩溃，重启 start.bat；确认防火墙放行 Python。
- **没有声音（系统语音引擎）**：点页面任意位置后再试（浏览器要求用户手势），或在系统设置中检查语音组件。
- **API Key 安全**：Key 仅保存在本机浏览器；若曾在任何公开场合粘贴过，请到方舟控制台立即重置。

## 部署说明

前端任意静态托管均可（GitHub Pages / Vercel / Nginx）；但**云端朗读依赖本地代理**，静态托管环境下仅系统语音可用。建议开启 gzip/brotli 压缩（`data/*.js` 压缩后约省 60~70% 体积）。
